# LJT-Homepage

Personal academic homepage for **Junteng Liu**, forked from [Academic Pages](https://github.com/academicpages/academicpages.github.io) and renamed to `LJT-Homepage` on GitHub under [`FastNavigator/LJT-Homepage`](https://github.com/FastNavigator/LJT-Homepage).

The site content uses only the profile details recorded in the connected memory:

- [`_pages/about.md`](_pages/about.md) — complete profile, academic background, research experience, publication list, skills, and contact information.
- [`_pages/publications.html`](_pages/publications.html) — dedicated publications subpage.
- [`_config.yml`](_config.yml) — site URL, author sidebar, and social/contact configuration.
- [`_data/navigation.yml`](_data/navigation.yml) — primary navigation.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open the local URL printed by Jekyll. For this project repository, the configured GitHub Pages path is `/LJT-Homepage/`.
